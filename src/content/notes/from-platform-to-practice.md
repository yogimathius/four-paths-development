title: From platform to practice
description: What changed when Pillars became one usable Hatha yoga path rather than a platform for five disciplines.
date: 2026-10-02

Pillars began with a larger frame: a platform containing five disciplines. That idea was coherent on paper, but it put a lot of structure between a person and the thing they had opened the app to do. The first release became narrower: Sādhana, a Hatha yoga curriculum that could be entered and practised without first understanding a whole system.

The narrowing changed more than the home screen. It changed what progress meant. Early versions spoke in weeks. A week is a useful unit for a release plan, but it can be an unhelpful unit for a practice. If you miss one, the interface can imply that you have fallen behind. Named stages and a self-paced path make a different promise: there is a place to continue, but no calendar to catch up with.

The same question shaped the practice screen. A phone can demonstrate a pose, time a sequence and hold a curriculum. It can also become the thing you keep checking. Spoken guidance carries the pose, breath and alignment cues so the screen can sit beside the mat. Visual references remain available when needed, but they do not have to command every moment of the session.

This is not an argument that software should disappear. It is a design constraint: the tool should be present where it helps and quieter where the activity itself needs the attention. That is a more useful test for Pillars than adding another dashboard.
